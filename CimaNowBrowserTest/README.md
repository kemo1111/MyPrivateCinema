# CimaNow Browser Test v2

نسخة اختبار منفصلة لسيما ناو. لا تستبدل ExampleProvider ولا تغيّر مصادره.

## التثبيت والاستخدام

1. أضف رابط `repo.json` الخاص بفرع `cimanow-test-builds` إلى مستودعات CloudStream، أو حدّث الإضافة لو المستودع موجود.
2. نزّل أو حدّث **CimaNow Browser Test** إلى الإصدار 2.
3. اختار المصدر، وافتح بطاقة **ابدأ اختبار متصفح سيما ناو** واضغط تشغيل.
4. اختار العمل من الموقع داخل نافذة المتصفح. أكمل التحقق العادي بنفسك، ثم اضغط تشغيل العمل من صفحة الموقع.
5. لو ظهر مرشح HLS أو MP4، اختار مرشح العمل فقط. المرشحات ممكن تشمل إعلانات. الاختبار يفحص أول جزء من الاستجابة قبل تسليمها للمشغل.
6. زر **شرح** يعرض حالة تحميل الصفحة وعدد المرشحات. زر إلغاء يقفل الاختبار. زر الرجوع في الجهاز يرجع في سجل المتصفح لو فيه صفحة سابقة.

البحث والقوائم في النسخة دي داخل الموقع فقط. خاصية Cast غير مدعومة.

## تغييرات الإصدار 2

- نافذة كاملة غير عائمة، وشريط تحكم صغير بدل التعليمات الطويلة فوق الصفحة.
- مساحة المرشحات مخفية تماماً قبل رصد مرشح، وبعدها تظهر كشريط أفقي صغير.
- عرض تقدم التحميل وأخطاء الصفحة. انتهاء تحميل المستند لا يمسح خطأ HTTP ولا يثبت نجاح تحقق الموقع.
- إغلاق نافذة الشرح مع إغلاق الجلسة.

## حالة التحقق وحدوده

- البناء نجح. اختبارات تمييز استجابة HLS/MP4 الخمسة واختبارات توزيع الواجهة وحفظ الخطأ والإغلاق نجحت.
- اختبارات الواجهة تستخدم Robolectric على API 28 و33، مع بديل اختباري للـWebView يحترم أبعاد الحاوية. لا تشغّل Chromium أو الموقع. الصور الناتجة معاينات مشروحة لتوزيع المساحة، وليست صور تشغيل الموقع على هاتف.
- في حاوية 800×360، مساحة المتصفح المحسوبة 800×313 قبل المرشحات، و800×257 مع مرشح واحد. في حاوية 640×270، المساحة 640×223 قبل المرشحات.
- تم فحص ملف DEX للتأكد إن كود المتصفح متضمّن، وإن اختبارات Robolectric ليست ضمن الإضافة.
- لم يتم إثبات عبور تحقق الموقع أو تشغيل فيديو فعلي بالإصدار 2. ده اختبار للواجهة ومسار المتصفح، مش إعلان إن سيما ناو اشتغل.
- المتصفح بيحتفظ بجلسة الموقع العادية. مفيش بروكسي أو خدمة توكن، ولا تسجيل لروابط الجلسة أو الكوكيز في ملفات. إعدادات هوية المتصفح وشهادة الأمان لم تتغير.
- مفيش ضغط آلي على التحقق أو الإعلانات، ولا كود محقون أو جسر JavaScript.
- النوافذ المفتوحة بضغطة المستخدم بتظهر في نافذة مرئية وبزر رجوع. الروابط غير HTTPS وروابط فتح التطبيقات الخارجية غير مدعومة.
- المرشحات محدودة بمسارات تنتهي بـ`.m3u8` أو `.mp4`. الروابط بلا امتداد، وDRM، والتحويلات أثناء الفحص غير مدعومة. فحص التوقيع لا يثبت إن الرابط للعمل الصحيح أو إن كل مقاطع HLS هتشتغل.
- الجلسة لها مهلة ٤ دقائق ونص. إلغاء التشغيل أو إغلاق شاشة التطبيق أو تدوير الجهاز بما يدمّر الشاشة يقفل الجلسة. لا يتم حذف كوكيز المستخدم العامة.
- لو الموقع عرض حظراً مستمراً أو طلب تحقق متكرراً، اقفل الاختبار بدل تكرار المحاولة.

## Code provenance

The experimental bridge, provider launcher and tests were written independently. No provider implementation from E2iPlayer, omarC or mehdigm-stream was copied. E2iPlayer informed the high-level browser-session direction, not the implementation. Android and CloudStream APIs are host/platform dependencies. Existing stable provider attributions remain unchanged.
